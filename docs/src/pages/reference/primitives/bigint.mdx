# T.bigint

A [scalar](/reference/primitives#scalars). Like [`T.string`](/reference/primitives/string), it can't be used bare, because there's no sensible default range. Call `.whereby({ min, max })` first.

```ts
T.bigint.whereby({ min: 0n, max: 1000n });
T.bigint.whereby({ min: { value: 0n, exclusive: true }, max: 1000n });
```

`T.bigint.as(produce)` replaces how the value is generated with your own function. See [`T.opaque`](/reference/primitives/opaque).
