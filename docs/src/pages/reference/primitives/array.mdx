# T.array

A [collection](/reference/primitives#collections): one shape, repeated a random number of times.

```ts
T.array(T.string.whereby({ length: { max: 15 } })).whereby({
  length: { min: 0, max: 10 },
});
```

Every element comes from the same schema. The length is drawn from `length.min` to `length.max`, including both ends. The draw is uniform unless you add a `distribution`, which works the same as for `T.number.integer` (see [Distributions](/guides/distributions)).

`length.min` defaults to `0`, so without a minimum, an empty array is a normal result. Either end can be exclusive: `{ min: { value: 0, exclusive: true }, max: 10 }` is never empty. A plain `length: N` always gives exactly N elements. See [Batches](/guides/relationships#batches).

For a fixed number of independently typed slots, see [`T.tuple`](/reference/primitives/tuple). For drawn keys instead of indices, see [`T.record`](/reference/primitives/record).
