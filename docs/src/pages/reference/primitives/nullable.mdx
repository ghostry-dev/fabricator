# T.nullable

An [absence](/reference/primitives#absence) primitive: either the inner schema's value or `null`. It is an ordinary schema you can use anywhere.

```ts
T.nullable(T.string.whereby({ length: { max: 10 } })); // string | null, 50/50
T.nullable(inner).weighted({ null: 1, value: 9 }); // null 10% of the time
```

For a value that can also be `undefined`, use [`T.nullish`](/reference/primitives/nullish), not `T.nullable(T.undefinable(inner))`. Nesting the two gives 50% `null`, 25% `undefined`, and 25% a value, instead of even odds. For a value that is always `null`, use [`T.null`](/reference/primitives/null).
