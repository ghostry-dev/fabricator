# T.recursive

A [structure](/reference/primitives#structures): a schema that refers to itself, such as a tree, a linked structure, or a generic JSON value.

```ts
const CategorySchema = T.recursive((self) =>
  T.object({
    name: T.string.whereby({ length: { min: 3, max: 20 } }),
    children: T.array(self).whereby({ length: { max: 3 } }),
  }),
).whereby({ depth: { max: 3 } });
```

`body` receives a `self` placeholder that means "recurse here". The value type, such as `children` being an array of categories in the example above, is inferred with no annotation, to any depth.

`.whereby({ depth })` is required, because a recursive schema with no limit would never stop. At `depth.max`, fabrication uses a _terminal_ schema instead of `body`. If you don't give one, it is built from `body` by turning every `self` that can stop into a stop:

- inside a `T.array` or `T.record`: an empty collection
- inside a [`T.choice`](/reference/primitives/choice): the remaining options that aren't `self`
- inside [`T.nullable`](/reference/primitives/nullable), [`T.undefinable`](/reference/primitives/undefinable), or [`T.nullish`](/reference/primitives/nullish): [`T.null`](/reference/primitives/null) or [`T.undefined`](/reference/primitives/undefined)
- inside [`T.omittable`](/reference/primitives/omittable) or [`T.optional`](/reference/primitives/optional): a left-out key

A `self` that is required, such as an object field, a tuple slot, or the whole body, can't be turned into a stop. Then `.whereby()` throws, and you must give a `terminal`.

A `terminal` you give _replaces_ the built one entirely, for example a custom leaf value or a JSON `choice` narrowed to one option. It doesn't patch the `self` spots inside `body`.

`depth` only has `max`, not `min`, on purpose. `T.array`, `T.record`, and `T.string` draw a count, so a `min` sets a floor on that draw. A recursive schema has no draw of its own. How deep a value goes depends on the kinds between `self` spots choosing not to recurse: an array drawing a length of 0, a choice picking a non-`self` option, or an optional field coming out absent. A real minimum would mean forcing those kinds' draws, which is a different feature. At `depth.max` the recursion has to stop, so the built terminal may empty a collection even if `body` set `length.min` above 0.

:::warning
If your own `terminal` empties a collection field, use [`T.opaque(() => [])`](/reference/primitives/opaque), not [`T.always([])`](/reference/primitives/always). `T.always([])` returns the _same array_ to every leaf, so pushing to one changes all of them. The built terminal already uses a new empty collection for each leaf. This only matters when you write `terminal` yourself.
:::

:::danger
`self` only works inside the `body` it was given to. Using it in a different `T.recursive` call, or outside any recursion, throws. There is no `T.self`.
:::

A body with two `self` fields, such as `left` and `right`, can produce `2^depth` nodes. Keep `depth.max` small, around 3 or 4, unless you have a reason not to.
