# T.always

A [literal](/reference/primitives#literals-and-choices): the same fixed value every time.

```ts
T.always("electronics");
T.always(42);
T.always({ status: "active" });
```

It can hold any value, not just strings, numbers, and booleans, and it always fabricates exactly that value. It has no `.as()`, because there's nothing to change about a fixed value.

An object or array is returned as the **same reference** on every call. For a _new_ value each time, such as a `Map`, a `URL`, or a class instance, use [`T.opaque`](/reference/primitives/opaque) instead.

To draw one of several fixed values, see [`T.enum`](/reference/primitives/enum). To draw one of several schemas, see [`T.choice`](/reference/primitives/choice).
