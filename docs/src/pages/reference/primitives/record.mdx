# T.record

A [collection](/reference/primitives#collections): random keys and values, each from its own schema.

```ts
T.record(
  T.string.whereby({ length: { min: 4, max: 12 } }),
  T.string.whereby({ length: { max: 40 } }),
).whereby({ size: { max: 6, minTried: 2 } });
```

Use it for keys you don't know when you write the schema, such as a metadata bag, a translation map, or a lookup by generated id. Keys and values both come from schemas, so you control a key's format like any other value.

`size` is `{ max, minTried }`, not `{ max, min }`, on purpose. Keys are drawn independently, so two can come out the same and collapse into one entry. `max` is a real upper bound, but the lower number is only _tried_, never guaranteed. With a wide key schema, such as a long string, collisions rarely matter. With a narrow one, such as a single digit, you'll often get fewer entries than you asked for. Fabricator never redraws a colliding key. Collapsing is the intended behavior.

:::warning
A `record` whose key schema can produce a symbol throws when converted to TypeBox. TypeBox's `Type.Record` can't represent symbol keys, and would otherwise silently return a schema (`TNever`) that nothing can pass. See [TypeBox](/guides/typebox).

:::
