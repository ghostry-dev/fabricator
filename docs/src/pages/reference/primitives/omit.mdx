# T.omit

A [structure](/reference/primitives#structures): a copy of an object schema without the fields you name.

```ts
const UserSchema = T.object({
  id: T.number.integer.sequence,
  name: T.string.whereby({ length: { min: 1, max: 25 } }),
  password: T.string.whereby({ length: { min: 12, max: 40 } }),
});

const PublicUserSchema = T.omit(UserSchema, ["password"]);
// { id: number; name: string }
```

`T.omit` is the opposite of [`T.pick`](/reference/primitives/pick), and everything on that page applies here too. If a computed field you kept reads a field you omitted, it still gets it: the omitted field is fabricated but left out of the result.

`T.omit` removes a field from the schema. To make a field sometimes missing from a fabricated object, use [`T.omittable`](/reference/primitives/omittable).
