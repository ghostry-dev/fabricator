# T.boolean

A [scalar](/reference/primitives#scalars). Used bare, it is `true` or `false` with equal odds.

```ts
T.boolean; // 50/50
T.boolean.weighted({ true: 3 }); // 75% true
```

`.weighted({ true, false })` sets the odds. You only need to give one side, and the other defaults to `1`. Weights are relative and don't need to add up to anything. A weight of `0` turns that side off, so `T.boolean.weighted({ true: 0 })` is always `false`. It throws if both weights are `0`. Negative weights, `NaN`, and `Infinity` are invalid.
