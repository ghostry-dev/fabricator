# T.undefined

An [absence](/reference/primitives#absence) primitive: always exactly `undefined`, with nothing to roll.

Useful as one branch of a [`T.choice`](/reference/primitives/choice), or as the `terminal` value of a field you want to disable entirely. For a value that might be `undefined` _or_ something else, use [`T.undefinable`](/reference/primitives/undefinable). For a field that might be missing from the object entirely, use [`T.omittable`](/reference/primitives/omittable).
