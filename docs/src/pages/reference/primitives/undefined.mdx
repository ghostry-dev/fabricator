# T.undefined

An [absence](/reference/primitives#absence) primitive: always exactly `undefined`. Nothing is random.

Use it as one option of a [`T.choice`](/reference/primitives/choice), or for a field that should always be `undefined`. For a value that might be `undefined` _or_ something else, use [`T.undefinable`](/reference/primitives/undefinable). For a field that might be left off the object, use [`T.omittable`](/reference/primitives/omittable).
